# GEA — Gestión Estudiantil Avanzada

GEA (Gestión Estudiantil Avanzada) es una plataforma web diseñada para facilitar la gestión académica y administrativa de escuelas, colegios y universidades. Su objetivo es centralizar de manera fácil y segura la información de estudiantes, docentes y directivos.

## 🚀 Características

- **Eficiente:** facilita la gestión y organización de la información.
- **Segura:** centraliza la información institucional de forma organizada.
- **Innovadora:** ofrece una solución digital orientada a la gestión educativa.

## 🎯 Misión

Brindar una plataforma eficiente que facilite la gestión académica y administrativa, mejorando la organización y el acceso a la información.

## 👁️ Visión

Ser el sistema líder en gestión educativa, reconocido por su innovación, seguridad y facilidad de uso en instituciones educativas.

## 🏫 Institución aliada

Actualmente, GEA se encuentra asociado con el **Colegio Nacional Ismael Perdomo Borrero**, ubicado en Gigante, Huila.

El proyecto contempla la posibilidad de incorporar posteriormente más escuelas, colegios y universidades.

- Seguimiento académico

- Noticias institucionales
- Anuncios

- Eventos

### 📅 Calendario

- Reuniones
- Eventos

- Fechas de entrega

## ▶️ Ejecución

La versión actual corresponde a una **versión Beta (2026)**.

Para visualizar la interfaz web:

1. Descarga o clona el proyecto.
2. Mantén la estructura de carpetas y archivos.
3. Abre el archivo `index.html` en un navegador web.
4. Asegúrate de que los archivos CSS, JavaScript e imágenes estén ubicados en las rutas correspondientes.
