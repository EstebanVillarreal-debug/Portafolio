wallpaper.py 
def color_rgb_segun_tiempo():
    ahora = datetime.now()

    segundos_totales =
        ahora.hour * 3600 +
        ahora.minute * 60 +
        ahora.second

    ciclo_segundos = CICLO_MINUTOS * 60

    posicion = (
        segundos_totales % ciclo_segundos
    ) / ciclo_segundos

    r, g, b = colorsys.hsv_to_rgb(
        posicion, 1.0, 1.0
    )

    return (
        int(r * 255),
        int(g * 255),
        int(b * 255)
    )
COLOR

¿Por qué cambia el color?

El programa transforma el tiempo actual en una posición dentro de un ciclo de colores. El valor HSV recorre el espectro cromático y después se convierte a RGB para poder utilizarlo en Pillow.

CICLO

¿Cada cuánto cambia?

La variable CICLO_MINUTOS determina cuánto tarda el color en recorrer todo el espectro. En este proyecto está configurada en 10 minutos.
